# NOVEX CLIENT

**NOVEX CLIENT** (`novex-client` v0.1.0) is a professional, stable, modular Minecraft Java Edition 1.21.11 client-side Fabric mod designed for PvP and Quality-of-Life (QoL).

## Key Features

- **Modular Architecture**: Isolated modules with real runtime functionality, clean state handling, and persistent configurations.
- **Mod Menu & Control Center Integration**: Configurable via Mod Menu or the default **Right Shift** hotkey.
- **Universal HUD Editor**: Draggable and resizable HUD elements with live grid-snapping, opacity, padding, scale, and preview mode.
- **Comprehensive HUD Modules**:
  - Armor HUD & Offhand / Totem Counter
  - Keystrokes & CPS Counter (Left, Right, Total)
  - Active Effects / Potion HUD
  - Inventory / Hotbar HUD
  - FPS, Ping, Server Info, Coordinates, Speed, and Direction HUD
  - Item Counters & Arrow Counter
  - Scoreboard Customizer
- **Visual & Rendering Utilities**:
  - Custom Crosshair Customizer
  - Low Fire / No Fire Overlay
  - No Fog & Fog Controls
  - Particle Reduction & Controls
- **Gameplay & Performance Enhancements**:
  - Dynamic Performance Modes & Visual Reduction Presets
  - Shield Usability Optimizer
  - FOV Zoom with smooth transitions & sensitivity scaling
  - Auto Sprint Utility
  - Quick HUD Clean / Hide Mode
- **Profiles & Config Persistence**: Save, duplicate, load, and switch between setup profiles saved locally in `.minecraft/config/novex-client/`.

## Target Environment & Build
- **Minecraft Version**: 1.21.11
- **Mod Loader**: Fabric Loader
- **API**: Fabric API & Mod Menu
- **Mod ID**: `novex-client`
- **Version**: `0.1.0`
